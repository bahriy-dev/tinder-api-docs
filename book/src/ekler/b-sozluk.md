# Ek B: Sözlük

| Terim | Açıklama |
| --- | --- |
| **X-Auth-Token** | Uygulama API'sine erişim için kullanılan oturum token'ı (UUID biçiminde) |
| **Refresh token** | Süresi dolan `X-Auth-Token` yerine yenisini almak için kullanılan uzun ömürlü token. Kullanıldığında kendisi de yenilenir. |
| **OTP** | *One-Time Password*: SMS ile gelen tek kullanımlık doğrulama kodu |
| **Protobuf** | Google'ın *Protocol Buffers* ikili veri biçimi. `/v3/auth/login` bu biçimi kullanıyor. |
| **Arkose Labs** | Tinder'ın kullandığı CAPTCHA ve bot algılama sağlayıcısı |
| **recs** | *Recommendations*: kaydırma destesindeki öneri kartları |
| **s_number** | Öneri kartına özel numara. Beğenme ve geçme isteklerinde geri gönderiliyor. |
| **content_hash** | Kart içeriğinin özeti |
| **teaser** | Kartta veya "Seni beğenenler" ekranında gösterilen kısa önizleme |
| **fast-match** | "Seni beğenenler" özelliğinin API'deki adı |
| **Boost** | Profili belirli bir süre öne çıkaran özellik 💳 |
| **Super Like** | Karşı tarafa özel olarak bildirilen beğeni |
| **Passport** | Kaydırma konumunu başka bir şehre taşıma özelliği 💳 |
| **Duos** | İki kişinin birlikte profil oluşturduğu "Double Date" modu |
| **Global mod** | Dünya genelinden öneri alma ve dil tercihi |
| **Tinder U** | Üniversite öğrencilerine özel keşif modu |
| **Yumuşak blok (soft block)** | Kısa süreli erişim kısıtlaması: boş öneri listesi veya hata |
| **Devre kesici (circuit breaker)** | Hata sonrası istekleri otomatik durduran tasarım deseni |
| **Jitter** | İstek aralıklarına eklenen rastgele sapma |
| **MCP** | *Model Context Protocol*: yapay zekâ ajanlarının dış araçlara bağlanma standardı |
| **OpenAPI / Swagger** | REST API'leri makine tarafından okunabilir biçimde tanımlama standardı |
| **KVKK** | 6698 sayılı Kişisel Verilerin Korunması Kanunu |
