# Davranış kuralları

Bu proje [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
davranış kurallarını benimser.

Özetle: Saygılı ol, iyi niyet varsay ve tartışmayı kişiler üzerinden değil
içerik üzerinden yürüt. Issue, pull request veya tartışmalarda **başkalarının
kişisel verilerini** (flört profilleri, fotoğraflar, mesajlar) asla paylaşma.

Kabul edilemez bir davranışı bildirmek için depo sahibiyle GitHub profili
üzerinden iletişime geç veya gizli bir
[güvenlik bildirimi](https://github.com/bahriy-dev/tinder-api-handbook/security/advisories/new) aç.
